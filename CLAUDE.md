# Live Aquarium

Интерактивный виртуальный аквариум для 24/7 YouTube-трансляций: спокойный ТВ/ASMR-режим, интерактивный режим (зрители управляют аквариумом из чата) и заготовки для Shorts. Пользователь общается по-русски — отвечать по-русски.

**Главное требование заказчика — реалистичность и качество картинки.** Текущий браузерный рендер (Three.js) — рабочий прототип логики. Картинку переносим в Unreal Engine 5: план в [docs/UNREAL_LOOKTEST.md](docs/UNREAL_LOOKTEST.md). Если ты сессия на Windows-ноутбуке — начни с этого файла.

## Как устроено

- `server/` — Node.js «режиссёр»: чат YouTube → правила (`parser.js`) → необязательный AI-парсер Claude (`ai-parser.js`, выбирает только из белого списка) → `director.js` (голоса, пороги от аудитории, кулдауны, приоритеты, антиспам) → события по WebSocket всем рендерам. `world.js` — мир и его сохранение, `catalog.js` — белый список событий и их правила.
- `renderer/` — браузерный рендер на Three.js. Ничего не решает сам: проигрывает события режиссёра. Рыбы — InstancedMesh со своим шейдером плавания (`renderer/js/fish/school.js`), часть видов — 3D-модели (`renderer/assets/models/*.glb`).
- Протокол рендер ↔ режиссёр описан в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Он сделан так, чтобы Unreal/Unity подключались вместо браузера без изменений сервера.
- Последствия, меняющие мир (кого съела акула, подарок золотой рыбки), решает режиссёр и передаёт в параметрах события; рендер только анимирует.

## Команды

```bash
npm install          # Node.js 20.6+
npm start            # http://localhost:8787  (/admin — пульт)
npm test             # 204 теста, должны проходить
node scripts/build-demo.mjs   # dist/demo (для claude.ai) и dist/site (обычный сервер)
./scripts/deploy-site.sh      # выложить статику на https://kd4.academy/aquarium/
```

Подготовка 3D-моделей (Blender 5.x): `Blender -b -P scripts/models/prepare.py -- <name>` — разворачивает модель в «пространство рыбы» (нос x=+0.5, длина 1), размечает плавники и челюсть в атрибуте `_AFIN`, ужимает текстуры, пишет GLB в `renderer/assets/models/`. Исходники моделей — `assets/models/raw/`, авторы — `assets/models/CREDITS.md` (CC BY: авторов нужно указывать).

## Правила, которые нельзя нарушать

- **Администратор может всё.** Любая проверка (роль, кулдаун, лимит, режим) первым условием пропускает администратора: владелец канала в чате и кнопки пульта проходят мимо всех ограничений. Если админ куда-то не может — это баг, чинить сразу.
- События — только из белого списка. AI не управляет движком напрямую, только выбирает событие из списка.
- Визуальные изменения проверять глазами, а не только тестами: крупные планы с разных сторон (сбоку, снизу, три четверти, сверху), днём и ночью, плюс серия кадров движения. Заказчик и пользователь смотрят на детали (форма, рот, крепление плавников, засветы).
- Скриншоты браузера — через Playwright.

## Грабли, на которые уже наступали

- Хостинг артефактов claude.ai не отдаёт `.glb`: в демо модели лежат как base64-текст (`scripts/build-demo.mjs`, `renderer/js/fish/models.js`).
- Строгий CSP демо блокирует `fetch` blob:-ссылок: картинки из GLB декодируются через `createImageBitmap`.
- Карты AO и цвета бликов из моделей Sketchfab делают рыбу чёрной / с оранжевыми искрами под нашим светом — отключены; карты шероховатости дают засветы под bloom — заменены константой.
- Скорость охоты акулы: без явного `maxOverride` её потолок — крейсерский, и она не догоняла жертву.
